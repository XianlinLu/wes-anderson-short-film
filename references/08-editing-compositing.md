# Lumina 剪辑合成规则

> 覆盖阶段 9。所有必需 `final_shot` 与 `final_audio` 就绪后执行。

先创建 `EDIT-v1 | Edit Decision List` String/text 节点，记录实际 `SHOT-XX`、`AUD-NAR-XX`、`AUD-SFX-XX`、`BGM-XX` 节点名/ID、分镜表 `shot_duration_seconds`、实测时长、入点、出点、轨道、音量、转场和状态。只有在当前 Lumina 画布真实提供时间线、合成或导出能力时才执行成片组装；否则交付经过验证的有序媒体节点与 EDL，并明确标记“未在画布中合成/导出”。

## 轨道布局

```
轨道1：视频（N个片段按分镜顺序拼接）
轨道2：旁白（如启用）
轨道3：音效
轨道4：BGM
```

## 音量层级

| 状态 | 旁白 | 音效 | BGM |
|-----|------|------|-----|
| 正常 | 0dB | -6dB | -12dB |
| 有旁白时 | 0dB | -12dB | -18dB |
| 纯音效陈述 | 静音 | 0dB | -20dB |
| 章节标题卡期间 | 静音 | 静音 | -18dB |

## 转场

- 默认：直切（cut）
- 镜间：默认直切，如直切点出现可见色彩 / 亮度接缝，允许加 **0.1s 亮度匹配过渡**（非淡入淡出，仅做相邻帧亮度均值对齐）。
- 章节边界：淡出 0.5s → 淡入 0.5s
- 片头：淡入 1s；片尾：淡出 1.5s

## 章节标题卡

- 仅使用静态版：3–4s 静帧；进入 0.3s 淡入，退出 0.3s 淡出。
- BGM 压低至 -18dB。

## 多段 BGM 合成（策略 B）

段落边界优先级：

1. **首选**：章节标题卡期间（标题卡前 0.5s 淡出，标题卡后 0.3s 淡入）
2. **次选**：情绪转折的镜间切换点（切点前后各 0.5s 内完成）
3. **禁止**：旁白中途切换

衔接方式：

| 情绪差异 | 方式 | 处理 |
|---------|------|------|
| 差异小 | crossfade | 淡出 1s，下段从 0.5s 处淡入，重叠 0.5s |
| 差异大 | 硬切 + 短淡入 | 直接切断，静默 0.2s 后淡入 1s |
| 有标题卡 | 利用标题卡缓冲 | 上段随标题卡淡出，下段在末尾淡入 |

## BGM 节点与画面节奏对齐

- 把既有 BGM 的可用强拍或乐句起点对齐至 M-Z+、M-Z-、M-XL、P-X、P-Z 或 `[CUT →]` 的实际时间点；优先通过轻微修剪音乐头尾和安排入点完成，不要求音乐生成阶段精确服从未验证的秒级强拍。
- 旁白期间不得中断句子或在单词中切换音乐；若无自然乐句边界，延后到章节标题卡或下一个镜间切点。

## 禁止操作

- 不变速 / 不加字幕 / 不叠色彩滤镜 / 不用 3D 转场 / 不压缩画幅

## Lumina 完成判定

- `SHOT-01` 至 `SHOT-N` 均可播放，顺序与已批准 `STORY-vN` 一致。
- 每镜实测时长与其 `shot_duration_seconds` 一致；每场与全片时长求和能与规格对账。
- 所有声音节点可试听并位于正确轨道；旁白、音效和 BGM 的实际电平设置符合上表。
- 转场、标题卡与音乐切换在真实时间线上可见，或已完整记录在 EDL 中。
- 导出存在时，记录导出节点/文件、分辨率、画幅、时长和可播放验证结果；排队、准备导出或仅创建 EDL 均不等于成片已导出。
- 当前画布不支持组装时，不创建虚构的合成节点，不把多个独立镜头描述为单一成片。
