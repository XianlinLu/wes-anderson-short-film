# 分镜设计规则

> 一至六节：在 `SPEC-vN | Final Video Spec` 确认后执行，并先于视觉资产生成完成。七节（叙事拓展）：素材分析标记「需故事拓展」时触发。

本文件产生的完整分镜保存在 `STORY-vN | Storyboard` 节点中。任何会改变镜数、连续性锁、声音层或资产绑定的修改都要递增版本，并重新确认受影响内容。

---

## 一、布景设计规范

**1. 场景即角色**：每个空间说明「谁住在这里」。书架 / 墙 / 桌上的物件都是叙事信息。

**2. 结构对称 · 内容非镜像（核心约束）**
- 结构层（墙面 / 门框 / 柱子 / 内置灯具）：允许对称
- 内容层（桌椅 / 道具 / 摆件）：左右内容必须不同，用视觉重量平衡

**娃娃屋 / 剖面构图使用条件**（满足任一才启用）：
- 空间本身是叙事主角（需展示系统结构 / 多活动并行）
- 全片开场定场镜头
- 章节开篇（可选）

**频率上限：全片剖面镜头 ≤ 20%**，其余使用正面平视写实构图。

**3. 年代锚定**：所有道具 / 家具 / 字体锁定 1930s–1980s，禁止当代品牌和数字设备。

年代跳变启用时（由色彩方案自主触发）：同一空间辉煌 → 衰败两版本，相同构图角度，材质退化 + 内容空置 + 色彩偏移（暖饱和 → 去饱和冷色）+ 画幅变化（11:8 → 12:5）。

**4. 角色制服**：每角色一个主色 + 一件标志道具，全片不变。

**5. 手工质感**：优先描述材质细节（木纹 / 皮革 / 墙漆 / 织物），道具精心陈列，不追求 photoreal。

## 二、线性叙事结构

开场（场所定义）→ 叙事段（每镜推进一个叙事信息）→ 高潮（情绪顶点）→ 结尾（闭环或定格）

## 三、分章节叙事

**章节命名**：自主命名（2–5 词名词短语，正式略带文学性），用户可调整。

**标题卡底材**：来自该章叙事世界本身：

| 叙事世界 | 适配底材 |
|---------|---------|
| 酒店 / 宫廷 | 模压门板、折叠餐巾、钥匙橱面板 |
| 法律 / 档案 | 法律文书信纸、手写文件、蜡封文件 |
| 学术 / 书房 | 旧书封面、手稿页、笔记纸 |
| 工厂 / 监狱 | 混凝土墙、粉笔黑板、金属门板 |
| 自然 / 旅行 | 手绘地图、植物标本纸、旧明信片 |
| 军队 / 制度 | 公文纸、档案封皮、官方表格 |
| 餐饮 / 社交 | 菜单封皮、桌布局部、酒标 |
| 医疗 / 科学 | 病历表、实验室记录单、标本容器标签 |

**每章内部结构**：切入镜头 → 核心镜头（1–4 个）→ 收束镜头

## 四、每镜必须包含

- 场景类型（A–G 或 T-10）
- 布景描述（三层规范：材质 / 内容 / 年代）
- 故事内容（台词 / 旁白文本）
- **角色朝向锁定**：逐角色、逐表演段标明且只可选一种——正对镜头（0°）、严格侧对镜头（90°）或背对镜头（180°）。禁止三分之二侧脸、斜侧脸、过肩构图、斜向视线和介于三态之间的停留姿态；需要改变朝向时，仅以明确完成的 90° 或 180° 转身衔接，转身后立即稳定在新的三态之一。
- **镜头 / 对象运动蓝图**：先定义 0 秒 `start_frame` 与收束静帧；再逐段标明唯一主导者（镜头或对象）、X/Y/中央 Z 轴路径、准确秒数及对应英文关键词。镜头仅可使用 M-00、M-Z+、M-Z-、M-XL、M-YU、M-YD；对象运动仅可沿画面 X 轴、Y 轴或中央 Z 轴直线进行（完整系统见 `references/04-camera-and-movement.md`）。
- **平面构图锁定类型**：从五类锁定语中选一（见 `references/05-prompt-writing.md` 的锁定语），写入分镜记录，供下游 Prompt 头部前置使用。
- **对称声明**：结构层（墙 / 门框 / 柱 / 内置灯具）左右对称；内容层（家具 / 道具 / 摆件）左右不镜像、以视觉重量平衡。
- 色彩插槽（见 `references/06-gbh-palette.md`）
- 声音标注
- **Lumina 节点绑定**：分镜总汇表第 1 行固定映射到 `VIDEO-SEED`，第 `k >= 2` 行固定映射到 `VIDEO-EXT-(k-1)`；不得跳行、合并行或重新分配时长。再列出每步使用的 `CHAR-XX`、`SCENE-XX`、`PROP-XX`、`FRAME-SEED-S0` 或可选 `FRAME-EXT-XX`，以及声音节点。使用真实节点 ID 或精确节点名；不存在的节点标记为 `planned`，创建后回填并复核。
- **时长与稳定画面**：每个叙事镜头在用户确认的分镜总汇表中有唯一 `shot_duration_seconds`，它就是对应视频调用的时长。`VIDEO-SEED` 必须使用第一行的完整时长；后续节点的 `added_duration_seconds` 必须等于对应行时长。每个视频步骤以「静止建立 → 单一轴线动作或一次硬切 → 静止读取」组织为 2–4 段，并使用独立的本地零起点时间轴。标题卡必须包含在对应分镜行时长中，不另生成用于拼接的标题视频。

> **运镜描述规则**：运镜只写代号和英文关键词，禁止用中文重新描述运镜方式。中文只描述叙事事件。
> ✗ 错误：M-XL（镜头从左向右横移跟随人物走路）
> ✓ 正确：M-XL · `lateral dolly strictly parallel to scene plane, camera never pushing into depth`

**镜内硬切与对象走位**：仅在两个稳定的正交平面之间写 `[CUT →]`；切前切后必须是正面、严格侧面、背面、严格俯视或严格仰视的二维静帧。对话正反打、车辆正面 → 驾驶者 / 车头第一视角、人物 → 道具正面特写直接硬切，禁止用摇镜、甩镜、旋转或绕行补桥。M-00 段内，人物、车辆和道具只能沿 X 轴、Y 轴或中央 Z 轴直线移动；横向入画后再沿中轴走入正中门洞时，必须分为两个明确的连续段，不得斜行、弧行或蛇形运动。

### 视频步骤运镜时间轴写法（每步新增时长由生成步骤表给出）

```
VIDEO-SEED / VIDEO-EXT-XX 运镜（`D = 对应分镜行的 shot_duration_seconds`）：
[0–Xs]:   运镜代号 · 英文关键词 · 叙事事件（中文）
[Xs–Ys]:  运镜代号 · 英文关键词 · 叙事事件
[Ys–Ds]:  运镜代号 · 英文关键词 · 叙事事件
```

> **时间轴写法要求**：实际输出时把 `D` 替换为本次种子或延长的新增秒数，每个节点都从本地 `00:00` 开始完整覆盖到 D，禁止把全片累计时间写进视频 Prompt。各段连续、无重叠、无空洞。每段先写 M-00 或单一轴向镜头运动；若镜头为 M-00 而对象在动，明确写「镜头锁定，对象沿 X/Y/中央 Z 轴直线运动」。

**示例（分镜表指定 18s；正面建立 → 横移 → 中轴离场）：**

```
[0–4s]:   M-00 · static locked shot, camera strictly perpendicular to scene plane · 角色A正面站定，翻阅信件。
[4–10s]:  M-XL · lateral dolly strictly parallel to scene plane, camera moves only on the X-axis · 摄影机横向跟随角色A穿过柜台。
[10–15s]: M-00 · static locked shot, camera strictly perpendicular to scene plane · 镜头锁定；角色A背对镜头，沿中央Z轴走入正中的门洞。
[15–18s]: M-00 · static locked shot, camera strictly perpendicular to scene plane · 门洞与空场景正面静止，叙事收束并作为下一镜切点。
```

十字轴线镜头与对象运动系统的完整代号表、禁止列表与分配约束见 `references/04-camera-and-movement.md`。

## 五、叙事单元：跨镜头组合模式

> 单个镜头是词汇，镜头组合是句子。以下七种模式定义跨镜叙事关系。

**两种底层句式结构：**
- **建立 → 揭示 → 反应**：先建立角色与环境 / 目标的关系，再揭示目标本身，再呈现角色对目标的反应。三镜构成一个认知闭环。
- **动作 → 道具 → 证明**：角色执行某个动作，切入该动作涉及的道具特写，再切回角色或结果——动作有了实物证据，叙事获得物质性。

以下七种模式是这两种句式在具体场景中的展开形式。

### 模式 1 · 行动 → 揭示（2–3 镜）

**结构**：角色与目标物的关系镜头 → 目标物正面特写（T-10）→（可选）角色反应镜头

**运镜**：镜 k 以 M-Z+ 推入道具后 M-00 静止；镜 k+1 为 T-10（M-00）；镜 k+2 以 `[CUT →]` 进入角色正面 M-00 反应镜头。

**约束**：镜 k+1 的道具 / 目标物必须是镜 k 中人物持有或注视的同一物件，不得替换。

### 模式 2 · 介绍 → 锚定（2 镜，逆序）

**结构**：道具 / 物件正面特写（T-10）→ 角色 + 场景全景（道具持有者及环境同时出现）

**运镜**：镜 k T-10（M-00）→ 镜 k+1 M-Z-（快速拉焦揭示场景全貌）

**约束**：道具在两个镜头中必须是同一件，外观 / 颜色 / 状态保持一致。

### 模式 3 · 对话组（2–N 镜，交替）

**结构**：人物 A 正面近景（M-00）→ 人物 B 正面近景（M-00）→ 可多次交替

**约束**：人物 A 与人物 B 之间仅用 `[CUT →]` 硬切；切前、切后都应是人物正面、严格侧面或背面的稳定平面构图。禁止摇镜、甩镜、弧形绕行与过肩角度。

### 模式 4 · 定位 → 框入（2 镜）

**结构**：俯拍或宽景建立空间位置关系 → 框景近距离揭示人物状态

**运镜**：镜 k 采用 M-00 严格俯拍全景或正面宽景建立位置关系 → `[CUT →]` → 镜 k+1 M-00 框景内静止。俯拍与框景分别独立建立，不用镜头俯仰旋转衔接。

### 模式 5 · 环境 → 框内（2–3 镜）

**结构**：外部视角横移建立环境 / 威胁 → 框景揭示内部人物反应 →（可选）框内主体特写

**运镜**：镜 k M-XL（平面横移）→ 镜 k+1 M-00（框景静止，框内外同时有信息）

**约束**：框内人物的反应必须与镜 k 的环境内容建立因果关系；框外信息和框内反应必须同帧可读。

### 模式 6 · 行动 → 留白 → 空间（3 镜）

**结构**：人物动作近景 → 人物离开后镜头停留在空场景（M-00，≥3s）→ 拉远揭示完整空间（M-Z-）

**约束**：中间静帧不少于 3s；M-Z- 后拉须沿中轴线，建筑立面封底。

### 模式 7 · 局部 → 系统（2 镜）

**结构**：单体建筑或人物的正面平拍 → 整体环境的剖面或宏观全景，揭示局部在系统中的位置

**运镜（标准版）**：镜 k M-00 → 镜 k+1 M-Z-（快速拉焦后拉）

**运镜（外景横扫变体）**：镜 k M-Z-（拉远揭示全貌）→ M-00（静止定帧）→ M-XL（横移扫过建筑立面）
外景城市街道时，此三步组合更接近安德森的城市外景节奏：先以 M-Z- 建立宏观尺度感，静止确认对称构图，再以 M-XL 将建筑立面的横向叙事信息依次展开。三段动作约需 10–15s，适合安排在一个镜头内。

**约束**：镜 k+1 中必须能找到镜 k 中的人物或建筑作为视觉锚点——两个镜头共享一个「可辨识元素」。

### 跨镜头连贯性约束（适用于所有模式）

- **道具连贯性**：同一组合内的道具在所有镜头中必须保持视觉一致（外观 / 颜色 / 状态）。视觉规格生成步骤须为该道具记录「道具锚定描述」，后续镜头提示词引用同一描述。
- **人物位置连贯性**：同一场景内相邻镜头中，人物相对空间的方向感必须一致。T-10 特写结束后，返回场景镜头的人物须回到相同空间位置。
- **色温连贯性**：同一场景内多个镜头色温不得漂移——色彩插槽在该场景所有镜头中保持相同，不因景别变化而调整。
- **节奏约束**：T-10 特写（M-00 静止）不得在单镜内连续超过镜头总时长的 50%；情绪顶点 M-Z+ 仅在全片 ≤2 个最强叙事时刻使用（其余推焦用于常规道具揭示）。

## 六、文字道具触发规则

- 位置：紧接角色拿起 / 使用道具的动作时间点前后
- 文字语言：遵循 `SPEC-vN` 的语言设定

**字体对应叙事世界：**

| 叙事世界 | 字体风格 |
|---------|---------|
| 默认 / 全局 | Futura（几何无衬线） |
| 酒店 / 宫廷 | Art Deco 粗衬线大写 |
| 法律 / 档案 | 混重量衬线（关键词加粗 + 虚词斜体） |
| 监狱 / 制度 | 手绘粉笔块字，大小不均 |
| 协会 / 俱乐部 | 大写衬线 + 斜体草书混排 |
| 学术 / 书房 | 经典均重衬线 |

## 七、叙事与角色拓展（素材分析标记「需故事拓展」时触发）

**7.1** 完整性判断由素材分析阶段输出并传递。需拓展时执行 7.2–7.5。

**7.2 角色拓展**：

层一 · 身份矛盾（选一原型）：

| 原型 | 公式 | 行为核心 |
|-----|------|---------|
| 延宕的青春期 | 成年躯体 + 未完成的童年心理 | 用某种固执的「过去标记」证明自己还没变 |
| 局外人渴望归属 | 被系统排斥 + 主动选择出发 | 哪怕失败也要出发，因为不出发才是真的消失 |
| 控制欲对抗失控 | 以极端秩序回应内心恐惧 | 越失控的内心，越精密的外部管理 |
| 光辉过去的幸存者 | 曾经辉煌 + 拒绝接受平庸当下 | 维持某种已消亡的生活方式，明知徒劳仍坚持 |
| 冷面深渊 | 外表极度克制 + 内部情绪极深 | 情绪太重反而不说；话越少，事越大 |

层二 · 视觉身份：主色 + 标志道具（**必须承载角色核心心理**）+ 姿态习惯

层三 · 行为模式：受创时反应 / 爱的表达方式

**7.3 叙事结构**：线性 / 嵌套（推荐章节化）/ 时间跳变

**7.4 情节触发**：身份危机 / 家庭裂变 / 遗嘱遗产 / 禁忌连接 / 冲动回归

**7.5 对话准则**：直面式（不藏信息）/ 最轻的话说最重的事 / 干冷节奏（deadpan）
