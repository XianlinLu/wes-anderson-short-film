# 生产流程（完整版）

> 适用于 1–3 分钟短片 · 十字轴线运镜 · 分镜表驱动逐镜时长

## Lumina 画布执行约定

- 开始前检查当前画布，建立真实节点与连接清单；复用可用素材、规格和已完成生成结果。
- 把全局规格保存为 `SPEC-vN | Final Video Spec` String/text 节点，把分镜与绑定表保存为 `STORY-vN | Storyboard`，把剪辑决策保存为 `EDIT-vN | Edit Decision List`。
- 所有图片、视频和声音 Prompt 写在对应生成节点内部。除上述持久文档节点外，不创建逐镜 Prompt 文本节点。
- 参考图片必须同时满足：真实连接到目标生成节点；Prompt 中通过 `@` 选择器插入可解析引用标签。手写 `@节点名` 不等于引用。
- 所有确认优先使用 Lumina 原生结构化选择对话。若当前画布不可用，保留已完成的分析和文档，不虚报节点、连接或生成结果。
- 首次可见回复或画布写入前先按 `references/language-routing.md` 确定 `interaction_language` 与 `story_language`，并将结果写入 `SPEC-vN`。

## 交互约定（全局）

- 不向用户提及内部阶段编号；所有面向用户的表述使用功能性描述（如「接下来完成角色、场景与道具的视觉资产」「当前分镜与关键帧确认后」「接下来生成视频片段」）。
- 每次暂停确认以选项形式呈现，禁止改为开放式文本提问：

```
✅ 确认，继续下一步
✏️ 修改当前内容
```

- 选「修改」→ 询问调整方向 → 重新生成 → 再次展示选项，循环至确认。

## 阶段 1：收集用户创作信息

**A. 创作素材**（任意组合）
- 故事 idea / 完整剧本 / 参考素材（图片 / 视频）

**B. 内容参数**（一次性收集）

| # | 参数 | 选项 | 默认 |
|---|------|------|------|
| 1 | 片名 | 自由输入 | 必填 |
| 2 | 目标时长 | 1 / 2 / 3 分钟 | 必选 |
| 3 | 短片语言 | 中文 / 英文 / 其他 | 中文 |
| 4 | 是否需要旁白 | 是 / 否 | 否 |

语言选择全片统一：旁白、画面文字、标题卡必须一致。

**C. 输出比例**（单独询问，三选一）

```
16:9  默认 · 横屏 · 外景/城市/制度场景效果最佳
4:3   接近学院比例 · 室内/私人空间/章节化叙事更合适
9:16  竖屏 · 手机优先 · 单人叙事/短视频场景
```

**D. 清晰度**（单独询问，二选一）

```
1080p  默认 · 成片交付、大屏展示
720p   快速预览、网络分发
```

> 输出比例（C）与清晰度（D）在阶段 2 单独询问；色彩模式在阶段 3 单独咨询。三者并列写入 `SPEC-vN | Final Video Spec`。

## 九个阶段与依赖

1. **需求与素材分析**：检查画布并收集故事、剧本和任务素材；为既有素材记录真实节点名/ID；分析并提取叙事、视觉与声音线索，输出剧本完整性结论。若需要扩展故事，将该结论作为后续分镜设计的输入。
2. **交付规格**：收集片名、总时长、成片语言、是否需要旁白、画幅（16:9 / 4:3 / 9:16）和清晰度（1080p / 720p）。
3. **色彩方案**：在素材分析和交付规格齐备后提出 A·GBH / B·自主设计 / C·自定义 方案；获得确认后锁定。
4. **全局规格**：建立 `SPEC-v1 | Final Video Spec` String/text 节点，写入已确认的全局参数、实际可用模型、叙事模式、章节结构、连续性锁和每个 `shot` 的目标时长。后续节点以此为共同锚点。
5. **剧本与生产台账**：如素材不完整，先完成故事与角色拓展；再按 `references/09-video-production-workflow.md` 锁定剧本，并在 `STORY-v1 | Storyboard` 中建立角色、场景、道具、声音需求和版本化生产台账。确认剧本与生产设定后再继续。
6. **角色、场景、道具与声音锁定**：生成或绑定 `CHAR-XX`、`SCENE-XX`、`PROP-XX`，完成整组资产确认。启用对白或旁白时，再生成独立声音试听并完成确认；所有下游节点只使用已确认版本。
7. **逐场分镜与视频**：一次处理一个场景。先创建并确认逐场分镜表，每行包含 `shot_duration_seconds`、`key_element`、动作、声音和绑定；再生成 `FRAME-XX-S0`、可选 `FRAME-XX-KN`、所需场景音频和 `SHOT-XX`。完整提示词放在视频节点内部，相关资产既物理连线又以 `@` 选择器插入引用。每镜请求时长与本地时间轴精确等于该行字段；当前场景确认后才进入下一场。
8. **其余声音层**：旁白、音效、环境声和 BGM 在对应场景分镜获确认后生成，且不得绕过已锁定的声音或场景依赖；分别保存为 `AUD-NAR-XX`、`AUD-SFX-XX` 和 `BGM-XX`，验证实际时长后绑定至相应镜头或剪辑层。
9. **合成**：所有必需镜头与声音就绪并获确认后，建立 `EDIT-v1 | Edit Decision List`；使用画布实际提供的合成/导出能力完成时间线。若当前 Lumina 画布无此能力，交付有序镜头、声音节点与 EDL，不宣称成片已合成。

**依赖关系**：3 依赖 1–2；4 依赖 3；5 依赖 4；6 依赖已确认的剧本与生产设定；7 依赖当前版本的已确认资产、声音和场景分镜表；8 依赖对应场景分镜与声音锁；9 依赖所有已确认场景视频与声音。每个标明暂停的里程碑都应提供「确认继续 / 修改当前内容」两个明确选项。

## SPEC-vN | Final Video Spec

色彩方案确认后按 `assets/final-video-spec.md` 建立此持久 String/text 节点，汇总用户选择、Lumina 实际可用模型和已确认的创作决策。分镜设计、媒体资产生成和剪辑合成均以它为全局基准，不得各自重新推断画幅、时长、语言、色彩或连续性规则。版本更新时使用 `SPEC-v2`、`SPEC-v3`，并记录受影响的下游节点。

## 阶段 3 · 色彩模式咨询

**前置检查**：素材含颜色信息时，先问用户是否直接以此为基础（选 A → 跳过主问题；选 B → 进入主问题）。

**主问题**（三选一，展示为选项）：

- **A · 模仿布达佩斯大饭店色调**
  立即展示 GBH 标准色板（见 `references/06-gbh-palette.md`），说明各色在场景中的角色。展示后等待确认。

- **B · 交给模型自主设计**
  根据故事情绪、场景类型、叙事弧自主设计色彩方案，可调用完整安德森色彩词汇（不限于 GBH）。展示方案后等待确认。

- **C · 自定义**
  用户自由输入颜色关键词 / 参考图 / 色彩描述，转化为色彩插槽方案，展示后确认。

**同时**提供自定义输入框（可不选 A/B/C 独立填写）。

**方案输出后**，展示确认界面：

```
✅ 确认当前色彩方案，开始设计视觉元素
✏️ 希望对当前方案进行调整
```

> **内部注意**：章节跳变色彩弧线、年代跳变色调衰减等色彩设计规则仍然有效（见 `references/03-storyboard-design.md` 与 `references/05-prompt-writing.md`），但不再作为用户选项——在 B 选项或色彩弧线设计阶段根据剧本自主判断是否适用并说明，用户在确认步骤中可调整。

## 镜头与时长规划参考

| 目标时长 | 建议镜数范围 | 分镜时长 | 章节上限 |
|---------|-------------|---------|---------|
| 1 分钟 | 3–8 镜 | 逐镜写入分镜表 | 1–2 章 |
| 2 分钟 | 6–16 镜 | 逐镜写入分镜表 | 2–3 章 |
| 3 分钟 | 9–24 镜 | 逐镜写入分镜表 | 3–4 章 |

镜数范围只用于初步规划，不决定单镜时长。每镜时长由已确认分镜表的 `shot_duration_seconds` 唯一定义；场景时长等于其镜头行之和，全片时长等于所有场景和已批准标题卡之和。当前模型无法表示某个时长时，先展示支持值并修改、重新确认分镜表，禁止静默取整。

> **3 分钟时的章节自动提议**：在色彩方案确认并建立 `SPEC-vN` 后，由分镜设计阶段提议章节结构与每章情绪基调，供用户确认后再生成视觉资产。
