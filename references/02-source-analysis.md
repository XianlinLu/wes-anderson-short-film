# 素材分析规则

> 在阶段 1 执行；输出叙事 / 视觉 / 声音线索与剧本完整性结论。

## Lumina 画布预检

分析故事前先读取当前画布中已有的 String/text、图片、视频和音频节点。为每个可复用素材记录：真实节点 ID 或精确节点名、媒体类型、可见内容、尺寸/比例、已有连接、生成状态和对应叙事用途。不要根据标签推断不可见内容，不要移动、替换或删除用户素材。

输出 `source_inventory` 并写入 `STORY-vN`：

```text
节点名/ID | 类型 | 可见内容 | 尺寸/比例 | 现有连接 | 拟绑定 key_element/shot/audio_layer | 状态
```

若素材尺寸或比例不适合已确认的输出画幅，保留原节点，并规划一个派生 FIT 资产；优先裁掉无关背景，否则扩展短边。禁止拉伸或重新塑造人物、服装、关键道具、文字和连续性细节。

## A. 剧本 / 故事文本

提取：

- **角色清单**：名称 / 身份 / 服装 / 身份色
- **场景清单**：地点 / 室内外 / 情绪类型 A–F（见 `references/05-prompt-writing.md` 的场景类型）
- **关键道具**
- **叙事文字道具（T-10 候选）**：标注名称 / 叙事功能 / 建议章节
- **情绪弧**
- **章节逻辑**

### 道具锚定预提取（跨镜连贯性前置）

分析阶段即为所有 T-10 候选道具输出初步视觉描述，格式如下：

```
道具锚定预描述 · [道具名]：
  形态：[形状/尺寸/材质]
  颜色：[主色/次色/破损/老化特征]
  可辨识细节：[印刷内容/图案/零件/标签/文字]
```

此预描述在分镜设计完成视觉规格时确认；后续所有提示词引用同一描述，不得重新描述。

## B. 视觉参考素材

提取：主色调、主情绪、空间感（尺度 / 平面化 / 娃娃屋感）、道具密度、声音线索（视频）。

**GBH 色板匹配判断**（阶段 3 前置信息）：若用户上传了参考图，分析时同步判断参考图色彩与 GBH 色板的接近程度，输出一行：

```
GBH色板匹配度：[高/中/低]
主要色差：[参考图中与GBH最大偏差的颜色描述]
阶段3建议：[直接用GBH / GBH为基础做调整 / 需另起炉灶]
```

此判断在阶段 3 开始时展示，作为色彩方案选择的参考依据。

## C. 限制

- 不分析真实人脸。
- 不复制品牌标识。
- 参考素材只提取语言规则（风格、质感、构图原则），不直接复制内容。

## D. 剧本完整性判断

**不需要拓展**（直接进入阶段 3）：有完整场景列表 + 具名角色 + 可推断叙事弧。

**需要拓展**（标记并传递至分镜设计阶段）：

| 输入类型 | 缺失 |
|---------|------|
| 概念 / 情绪方向 | 场景 / 角色 / 事件全部缺失 |
| 人物概念 | 有角色无场景无事件 |
| 主题词 | 无具体叙事要素 |
| 不完整剧本 | 缺台词 / 动作 / 视觉描述 / 结局方向任一 |
| 仅视觉参考无文字 | 无叙事内容 |

标记输出：

```
完整性判断：[需故事拓展 / 不需要拓展]
缺失内容摘要：[具体缺失项]
```
